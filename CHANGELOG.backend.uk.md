# Журнал змін Backend

[English version](CHANGELOG.backend.md)

## 4.0.0 — 2026-08-02

- Runtime перейменовано на DataSetsManager Server без зміни маршрутів `/v1`.
- Додано канонічні налаштування `DSM_*` із сумісністю `IVINS_*` на одну major-версію.
- Додано канонічні псевдоніми профілів і безпечну нормалізацію бази на місці.
- Нові API-ключі мають префікс `dsm_`; наявні `ivins_` чинні протягом 4.x.

## 3.3.0 — 2026-08-02

- Додано валідований канонічний маніфест версій компонентів.
- Додано публічний `GET /versions` і версії компонентів до status responses API.
- `server_version` збережено як зворотно сумісний псевдонім Backend.
- Додано сумісність Process для автоматизованих перевірок розгортання.

## 3.2.0 — 2026-08-02

- Додано профілі в межах сімейства, профіль за замовчуванням нормалізовано до `all`.
