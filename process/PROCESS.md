# Process dependency

[Українська версія](PROCESS.uk.md)

This server release depends on **DataSetsManager Process 2.0.0**.
The canonical policies, permissions, prohibitions, ITSM procedures, release
gates, and incident/change records are maintained in
[`DataSetsManager/DataSetsManager`](https://github.com/DataSetsManager/DataSetsManager).

The immutable Process 1.0.0 snapshot that originally lived in this repository
is retained at [`archive/PROCESS-v1.0.0.md`](archive/PROCESS-v1.0.0.md) for audit
and rollback evidence. It is no longer the current policy source.

The required Process version and compatibility range are machine-readable in
[`versions.json`](../versions.json).
